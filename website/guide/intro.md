# 项目简介

**Weibo Crawler** 是一个基于 Python 编写的新浪微博爬虫与数据采集工具，旨在为数据分析、自然语言处理、舆情研究以及个人数字备份提供稳定可靠的数据抓取方案。

## 核心特性

- **多用户连续爬取**：支持爬取一个或多个微博用户的全部或增量数据。
- **免登录与登录双模式**：
  - **免登录模式**：无需提供任何 Cookie，即可爬取公开微博及绝大多数用户信息。
  - **Cookie 模式**：突破匿名数量限制，支持获取历史海量微博、关键词搜索与转发抓取。
- **丰富的输出格式**：
  - 默认输出便于表格分析的 **CSV** 文件。
  - 结构清晰完整的 **JSON** 数据文件。
  - 关系型数据库 **MySQL** 与轻量本地数据库 **SQLite**。
  - 文档型数据库 **MongoDB**。
  - 自动通过 HTTP **POST Webhook** 实时分发数据。
- **多媒体资源完整归档**：
  - 原创微博与转发微博的原始高清图片。
  - 微博高清视频及 Live Photo 动态照片提取。
  - 自动将微博发布时间写入图片 EXIF 元数据，便于照片墙和相册整理。
- **评论与互动数据抓取**：
  - 原创与转发微博的一级评论采集（支持数量上限限制）。
  - 微博转发链条及转发理由采集。
- **生产级运行能力**：
  - 支持 Docker 容器化打包与 Docker Compose 部署。
  - 内置基于 Flask 的 RESTful API 接口，可通过外部系统远程调用爬虫。
  - 支持 PushDeer 推送 Cookie 异常通知。

## 运行环境

| 环境项 | 最低要求 | 推荐配置 |
| --- | --- | --- |
