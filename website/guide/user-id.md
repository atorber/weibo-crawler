# 如何获取 User ID

每个新浪微博账号都有一个全局唯一的数字身份标识，即 `user_id`（例如：迪丽热巴的 `user_id` 为 `1669879400`）。

## 标准获取流程

1. 浏览器打开手机版微博网页端：[https://weibo.cn](https://weibo.cn)。
2. 在搜索框内检索目标博主昵称（如 "迪丽热巴"），进入其主页。
3. 点击主页菜单栏中的 **"资料"** 链接，浏览器将跳转至类似如下地址：
   ```
   https://weibo.cn/1669879400/info
   ```
4. 其中路径段中的数字 `1669879400` 即为所需要的 `user_id`。

---

## 避坑说明：为什么不直接从主页 URL 提取？

许多博主设置有个性域名或微号：
- 部分用户的主页 URL 是形如 `https://weibo.cn/个性域名?f=search_0`
- 部分用户的主页 URL 是形如 `https://weibo.cn/微号?f=search_0`

虽然微号表面上也是一串数字，但它与数据库真实的全局 `user_id` 并不一致！**唯有点击进入“资料”页后 URL 中显示的纯数字，才是唯一准确的 `user_id`**。

---

## 批量配置技巧

如果需要爬取成百上千个博主，推荐使用文本文件配置：

1. 在项目根目录创建 `user_id_list.txt`，每行一个博主：

```text
1223178222 胡歌
1669879400 迪丽热巴
1729370543 郭碧婷
```

2. 在 `config.json` 中指定文件路径：

```json
{
  "user_id_list": "user_id_list.txt"
}
```

爬虫在执行时将自动逐行解析，用户 ID 后面的昵称备注会自动忽略，方便团队维护。
