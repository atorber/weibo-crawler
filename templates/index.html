基础采集设置

仅爬取原创微博 (only_crawl_original) 开启后跳过所有转发微博，仅抓取博主独立原创的内容
清洗过滤 HTML 标签 (remove_html_tag) 过滤正文中的 a 标签、超链接代码，保留纯文本正文
指定用户 ID 文件路径（如 user_id_list.txt）或逗号/换行分隔的多个用户 ID
所有生成的文件、媒体以及报告统一存储的根目录名称（默认：weibo_data）
可以是日期格式（如 2024-01-01）或正整数天数（如 7 代表最近7天）
为空则不限制，格式：YYYY-MM-DD 或 YYYY-MM-DDTHH:MM:SS
⏰ 开启持续监听模式 (schedule_config.enabled) 开启后每轮抓取完成自动等待指定间隔，再自动拉起下一轮增量巡检（仅拉取最新发布的微博）

Cookie 认证与报警

🌐 从本地浏览器一键同步 Cookie
直接从 Chrome、Edge、Firefox、Safari、Arc 等读取已登录凭证，免手动复制
🔄 开启浏览器 Cookie 自动更新与失效热恢复 (cookie_auto_config.enabled) 开启后无需手动提取，支持爬虫遇到 403/认证失效时自动从本地浏览器提取最新 Cookie 并无缝重试，以及后台定时同步
⚡ 爬虫运行中遇到 403/432/认证失效时自动热更新并重试 (refresh_on_expire) 抓取中途若触发认证拦截或登录态过期，自动重提浏览器 Cookie 热替换 Session，不中断当前任务
🛡️ 每次启动爬虫任务前自动校验并刷新失效 Cookie (check_before_start) 点击启动爬虫前自动探针检测，若当前 Cookie 已失效则先从浏览器提取最新凭证再启动

图片与多媒体下载

下载原创微博图片 (original_pic_download) 自动保存原创微博的原始无损大图
下载转发微博图片 (retweet_pic_download) 仅在未开启“仅爬取原创”时生效
下载原创微博视频 (original_video_download) 保存原创微博高清 MP4 视频到本地
下载转发微博视频 (retweet_video_download) 保存转发微博中的高清视频文件
提取原创 Live Photo 视频 (original_live_photo_download) 单独提取原创动态照片中的视频流
提取转发 Live Photo 视频 (retweet_live_photo_download) 单独提取转发动态照片中的视频流
下载评论中附带的图片 (comment_pic_download) 抓取评论内容中用户上传的配图文件

同步修改文件系统时间 (change_file_time) 将本地下载的媒体文件系统创建/修改时间同步为微博发布时间
📁 本地媒体存储子目录名称映射 (download_folder_name)

🔌 RESTful API 接口中心

提供标准化 HTTP 接口供外部系统、微服务、定时脚本或自动化流水线深度集成与远程调度。

BASE URL: http://127.0.0.1:15001
GET /api/status
获取服务运行状态、进程信息与大屏核心监控指标
响应示例 (200 OK)
{
  "code": 200,
  "data": {
    "status": "RUNNING",
    "is_running": true,
    "pid": 58321,
    "duration": "00:05:21",
    "current_user": "迪丽热巴",
    "crawled_count": 86,
    "metrics": { "user_count": 3, "total_weibos": 1420, "db_connected": true }
  }
}
POST /api/service/start
启动后台微博数据采集子进程 (weibo.py)
请求体 (JSON, 可选)
// 指定本次运行仅采纳的用户列表（留空则默认按监控列表执行）
{
  "user_id_list": ["1669879400"]
}
POST /api/service/stop
优雅停止正在运行中的爬虫子进程 (SIGTERM，已采数据自动保存)
响应示例 (200 OK)
{
  "code": 200,
  "success": true,
  "message": "爬虫已成功停止",
  "data": { "status": "STOPPED" }
}
POST /api/service/restart
停止当前爬虫并以最新配置重新拉起进程
请求体 (JSON, 可选)
{
  "user_id_list": ["1669879400"]
}
GET /api/users
获取当前已配置的目标博主列表与增量采集参数
响应示例 (200 OK)
{
  "code": 200,
  "total": 1,
  "data": [
    { "id": "1669879400", "screen_name": "Dear-迪丽热巴", "since_date": "2024-01-01", "query": "" }
  ]
}
POST /api/users
添加新目标博主或修改已有博主采集参数
请求体 (JSON)
{
  "id": "1669879400",          // 必填：纯数字 UID
  "screen_name": "迪丽热巴",    // 可选：个性化备注
  "since_date": "2024-01-01",  // 可选：起始日期或天数
  "query": "活动,日常"         // 可选：关键词过滤
}
DELETE /api/users/<user_id>
从监控目标队列中移除指定的博主
调用示例
curl -X DELETE http://127.0.0.1:15001/api/users/1669879400
POST /api/users/import
支持多行文本批量导入目标博主（追加或覆盖）
请求体 (JSON)
{
  "text": "1669879400 迪丽热巴 2024-01-01\n1223178222 胡歌",
  "mode": "append"  // "append" (追加) 或 "overwrite" (覆盖)
}
GET /api/config
读取当前生效的 config.json 原始文本与结构化解析字典
响应示例 (200 OK)
{
  "code": 200,
  "raw": "{\n  \"cookie\": \"...\"\n}",
  "parsed": { "write_mode": ["csv", "sqlite"], "cookie": "..." },
  "is_custom_config": true
}
POST /api/config
在线校验并保存配置（支持 raw 字符串或 parsed 字典对象）
请求体 (JSON)
{
  "parsed": {
    "only_crawl_original": 1,
    "write_mode": ["csv", "sqlite", "mysql"]
  }
}
POST /api/cookie/check
探针测试指定或已存 Cookie 的连通有效性、网络时延与用户信息
请求体与响应
// Request Body (可选，不传测试已保存 Cookie):
{ "cookie": "SUB=xxx; SUBP=yyy;" }

// Response (200 OK):
{
  "code": 200,
  "valid": true,
  "message": "Cookie 有效！响应时延: 168ms",
  "user": { "id": "2837199120", "screen_name": "开发者" }
}
GET /api/cookie/browsers
探测本机已安装且支持免密提取 Cookie 的浏览器列表
响应示例 (200 OK)
{
  "code": 200,
  "rookiepy_available": true,
  "browsers": [
    { "id": "auto", "name": "自动探测已登录浏览器 (推荐)" },
    { "id": "chrome", "name": "Google Chrome" },
    { "id": "edge", "name": "Microsoft Edge" }
  ]
}
POST /api/cookie/import_browser
一键从本地浏览器安全提取微博已登录 Cookie（仅限 localhost 调用）
请求体 (JSON)
{
  "browser": "auto",  // 浏览器标识符 ("auto", "chrome", "edge" 等)
  "save": true        // 提取成功后是否自动写入 config.json
}
POST /api/test/mysql
在线测试 MySQL 数据库连接、认证握手与时延
请求体 (JSON)
{
  "host": "127.0.0.1", "port": 3306,
  "user": "root", "password": "yourpassword", "charset": "utf8mb4"
}
POST /api/test/mongodb
在线测试 MongoDB 数据库连接与版本状态
请求体 (JSON)
{
  "uri": "mongodb://localhost:27017/weibo?authSource=admin"
}
POST /api/test/webhook
向 Webhook 接口发送 ping 探测包并测试 HTTP 响应状态
请求体 (JSON)
{
  "url": "https://api.example.com/webhook",
  "token": "secret_token_123"
}
GET /api/logs
拉取内存缓冲区实时运行日志行（支持等级和关键字检索）
Query 参数
?limit=200&level=ALL&keyword=正在抓取
GET /api/data/weibos
多维条件检索与分页查询 SQLite 数据库中的已入库微博数据
Query 参数与响应
// Request: ?page=1&page_size=10&user_id=1669879400&start_date=2024-01-01&end_date=2024-01-07&keyword=活动
// Response (200 OK):
{
  "code": 200,
  "data": {
    "total": 128, "page": 1, "page_size": 10,
    "items": [ { "id": "49581902830182", "screen_name": "迪丽热巴", "text": "活动照" } ],
    "available_users": [ { "user_id": "1669879400", "screen_name": "迪丽热巴" } ]
  }
}
POST /refresh
经典兼容触发接口（返回 202 Accepted 或 409 Conflict，含 task_id）
请求体 (JSON, 可选)
{ "user_id_list": ["6067225218"] }
GET /task/<task_id>
经典兼容任务进度状态轮询接口
响应示例 (200 OK)
{
  "state": "PROGRESS",
  "progress": 50,
  "result": { "status": "RUNNING" }
}
