基础采集设置

仅爬取原创微博 (only_crawl_original) 开启后跳过所有转发微博，仅抓取博主独立原创的内容
清洗过滤 HTML 标签 (remove_html_tag) 过滤正文中的 a 标签、超链接代码，保留纯文本正文
指定用户 ID 文件路径（如 user_id_list.txt）或逗号/换行分隔的多个用户 ID
所有生成的文件、媒体以及报告统一存储的根目录名称（默认：weibo_data）
可以是日期格式（如 2024-01-01）或正整数天数（如 7 代表最近7天）
为空则不限制，格式：YYYY-MM-DD 或 YYYY-MM-DDTHH:MM:SS

Cookie 认证与报警

在 weibo.com 或 m.weibo.cn 登录后从浏览器网络面板复制的完整 Cookie

图片与多媒体下载

下载原创微博图片 (original_pic_download) 自动保存原创微博的原始无损大图
下载转发微博图片 (retweet_pic_download) 仅在未开启“仅爬取原创”时生效
下载原创微博视频 (original_video_download) 保存原创微博高清 MP4 视频到本地
下载转发微博视频 (retweet_video_download) 保存转发微博中的高清视频文件
提取原创 Live Photo 视频 (original_live_photo_download) 单独提取原创动态照片中的视频流
提取转发 Live Photo 视频 (retweet_live_photo_download) 单独提取转发动态照片中的视频流
下载评论中附带的图片 (comment_pic_download) 抓取评论内容中用户上传的配图文件
写入图片 EXIF 拍摄时间 (write_time_in_exif) 将微博发布时间写入照片 EXIF 元数据
同步修改文件系统时间 (change_file_time) 将本地下载的媒体文件系统创建/修改时间同步为微博发布时间
📁 本地媒体存储子目录名称映射 (download_folder_name)
自定义不同媒体类型在本地创建的存储子文件夹名称

数据输出格式 (write_mode)

使用 UID 作为文件夹名称 (user_id_as_folder_name) 关：使用用户昵称（如 Dear-迪丽热巴）；开：使用纯数字 UID
🐬 MySQL 数据库连接配置 (mysql_config) write_mode: mysql
推荐保持 utf8mb4 以完整支持 Emoji 表情符号
🍃 MongoDB 数据库连接配置 (mongodb_URI) write_mode: mongo
标准 MongoDB 连接字符串，例如包含鉴权数据库的完整 URI
📦 SQLite 本地数据库配置 write_mode: sqlite
在 SQLite 中存储媒体二进制 (store_binary_in_sqlite) 开启后将图片/视频的二进制原始字节直接存储在数据库 BLOB 字段中
🌐 HTTP POST Webhook 转发配置 (post_config) write_mode: post
📝 Markdown 归档与排版配置 write_mode: markdown
生成缺失微博排查报告 (missing_weibo_report) 每次抓取结束后生成与上次相比缺失（被删除/被屏蔽）的微博报告
🖼️ Markdown 内容嵌入预览开关 (markdown_preview)
📂 Markdown 内部媒体相对链接目录 (markdown_file_dir)

互动抓取与高级选项

下载一级评论 (download_comment) 抓取微博下方的一级评论（主要用于 SQLite / CSV 写入）
下载转发链条 (download_repost) 抓取微博转发历史与转发理由

启用智能反封禁防护引擎 (enabled) 根据会话时长、错误率自动触发动态延迟与间歇休息，规避账号被风控
